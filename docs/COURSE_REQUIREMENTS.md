## 技术选型与边界

课程允许 CLI 或 GUI 的 Python 应用；并未明确要求 Flask、Django、数据库、机器学习或复杂算法。项目提供真正可操作的 Python CLI，避免仅把网页服务器换语言后忽略 CLI / GUI 的要求。浏览器是完整业务的附加界面。

项目仍是本地课程演示：没有真实支付、实名认证、邮件验证。名为 AI 润色的功能是本地文本规则，不是调用生成式大模型；课程加分所指的 AI 开发协作，另见 AI 使用记录。

后续新增的双边匹配采用真正可训练的轻量 Transformer + 异构图网络，需要 PyTorch / NumPy；结构、合成训练数据和验证边界详见 `MATCHING.md`。它与本地文本润色是两个独立功能。展示时应说明每项技术的作用，并明确合成实验不代表真实用户推荐效果。

## 提交前验收

- [ ] 核对 Moodle 的小组人数、提案与各项截止时间。
- [ ] 所有成员理解并能解释自己的代码和测试；完成代码来源核查。
- [ ] `python main.py` 可启动 CLI，非法输入不会退出程序。
- [ ] `python main.py --serve` 可打开网页并完成一次预约与私聊。
- [ ] `python -m unittest discover -s tests -v` 全部通过。
- [ ] 生成实际组号的 ZIP，在新目录中解压后复测。
- [ ] 上传 ZIP（含测试）、PPT、15 分钟视频；个人报告各自提交 PDF。
- [ ] 课堂讲解不超过 5 页和 5 分钟；完成同伴评估。

成员身份、组号、分工和个人贡献由小组自行填写，不在本次修改中代填。
